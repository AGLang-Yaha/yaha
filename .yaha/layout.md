# YAHA Workspace Layout

/.yaha/                            # configuration folder to yaha
  ├── logs/                 # all previous trajectories
  ├── skills/                # all dynamically discoverable skills
  ├── resources/              # all related resources for agent classes
  ├── AgentClass.md     # defines all agent classes
  ├── Model.md               # defines all models
  ├── SOUL.md               # agent identity + optional per-class sections
  └── tool-schema.md   # json schema for tools
