# Instructions

This skill leverages a Docling-based script to convert a digital PDF (not a scanned image pages) to Markdown format. 
`python scripts/pdf2markdown-text.py <filename>.pdf -o <filename>.md` 


# Rubric 

- Use `ls -l` to check if the converted file exists
